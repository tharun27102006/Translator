# CityVoice Comment Platform

A responsive comment section with multilingual posting, translation support, and automatic moderation.

## Features
- Post comments in any language.
- Translate each comment to a selected target language.
- Show city context on every comment card.
- Like and dislike interactions.
- Auto-remove comment when total dislikes reach 2.
- Block comments containing unsupported special symbols.
- Responsive design for mobile, tablet, and desktop.

## Local Run
1. Open this folder in VS Code.
2. Open index.html directly in your browser.

## Deploy on Vercel
1. Run:
   npx vercel login
2. Complete browser login.
3. Run:
   npx vercel --prod --yes
4. Copy the generated https URL and submit it.

## Deploy on Netlify
Option A:
- Drag and drop the folder in Netlify Drop.

Option B:
1. Install Netlify CLI.
2. Run:
   netlify deploy --prod
3. Copy the generated https URL and submit it
