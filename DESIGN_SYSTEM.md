# CityVoice Design System

## Visual Direction
- Style: Minimalist, clean, and spacious.
- Mood: Calm and trustworthy for community discussions.
- Principles: Accessibility first, high readability, predictable interaction.

## Color Palette
- Primary blue: #1d4ed8
- Light blue surface: #dbeafe
- White: #ffffff
- Light beige background: #f7f2e8
- Text primary: #212121
- Text secondary: #5b5b5b
- Error red: #b91c1c

## Typography
- Heading font: Space Grotesk
- Body font: Outfit
- Emphasis through weight and spacing, not heavy decoration.

## Spacing
- Large whitespace around major sections.
- Comfortable line height for long comments.
- Rounded containers with subtle shadows.

## Responsive Rules
- Mobile-first behavior.
- Main layout constrained to readable width on desktop.
- Controls stack vertically on small screens.
- Touch targets remain easy to tap.

## Comment UX Rules
- Users can submit comments in any language.
- City label shown on each comment.
- Like, dislike, and translate actions visible together.
- Comments with unsupported special symbols are blocked.
- Comment is auto-removed when dislikes reach 2.
